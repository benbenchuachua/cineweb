# Dodge3D

Reaction-time browser game. Asteroids fly toward you — tap them before they hit. One miss ends the run.

## Run locally

```bash
cd dodge3d
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```

High scores are stored in `localStorage` under `dodge3d-highscore`.
